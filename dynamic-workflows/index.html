Dynamic Workflows —
מאות סוכנים בהרצה אחת

רוב מי שמשלם על Claude Code אפילו לא יודע שזה קיים. הפרומפט המדויק שמפעיל מאות סוכנים במקביל על משימה אמיתית — עם תקרת טוקנים מובנית, כדי שההרצה הראשונה תהיה בטוחה ולא תשרוף לך את המכסה.

1מילה מפעילה
100+סוכנים במקביל
15kתקרת טוקנים בטוחה

⚙️ 30 שניות הכנה לפני שמתחילים

  1. ודא שאתה על Claude Code v2.1.154 ומעלה — בטרמינל: claude --version
  2. במסלול Pro: פתח /config והדלק את השורה Dynamic workflows. במסלולי Max / Team / Enterprise זה כבר דלוק.
  3. היכנס לתיקיית הפרויקט שלך ופתח את Claude Code.

הפרומפט — מוכן להעתקה

המילה ultracode בתחילת השורה היא מה שמפעיל את ה-workflow. התקרה use 15k tokens שומרת עליך בהרצה הראשונה. שנה את הנתיב לתיקייה שלך.

CODE

סריקת אבטחה — כל ה-routes במקביל

מה זה עושה: מפצל את כל הקבצים תחת ./src/routes למאות סוכנים, כל אחד בודק קובץ אחד, ואז הסוכנים מצליבים ממצאים זה מול זה לפני הדיווח — פלט אחד מסודר לפי רמת סיכון.
ultracode: Audit every file under ./src/routes for missing authentication
checks. For each route, report the file, the HTTP method, and whether an
auth/permission check is present before the handler runs. Cross-check
findings between agents before reporting. Output a single table sorted by
risk. Use 15k tokens.

גרסה עברית — מציאת סתירות במסמכים

מתי להשתמש: כשיש לך הרבה מסמכים דומים ואתה רוצה לבדוק עקביות. עובד מצוין למשימות שאינן קוד — מחקר, ביקורת תוכן, השוואות.
ultracode: עבור על כל קובצי ה-Markdown בתיקייה ./docs ומצא סתירות בין
מסמכים — מקומות שבהם שני מסמכים אומרים דברים שונים על אותו נושא. כל סוכן
בודק חתיכה אחת, ואז הסוכנים מצליבים ממצאים זה מול זה לפני הדיווח. פלט:
טבלה אחת של הסתירות שנמצאו. Use 15k tokens.

איך מריצים — צעד אחר צעד

שלוש פקודות, וזהו. אחרי הרצה מוצלחת אפשר לשמור אותה כפקודה קבועה.

1

הדבק את הפרומפט והרץ

המילה ultracode בתחילת הפרומפט אומרת ל-Claude לכתוב סקריפט שמפצל את המשימה למאות סוכנים, במקום לעבוד עליה תור-אחר-תור.

2

אשר את ה-workflow

Claude יציג את השלבים המתוכננים וישאל. בחר Yes, run it. ההרצה רצה ברקע — הסשן נשאר פנוי.

3

עקוב עם /workflows

בחר את ההרצה ו-Enter כדי לראות כל שלב: כמה סוכנים, כמה טוקנים, וכמה זמן. p לעצירה/המשך.

4

שמור עם s

אם ההרצה עשתה מה שרצית — בתוך /workflows לחץ s כדי לשמור אותה כפקודה משלך. בפעם הבאה זה רק /<שם>.

⚠

כלל זהב: התחל קטן

Dynamic Workflows שורף הרבה יותר טוקנים מסשן רגיל. הרץ קודם על תיקייה אחת, תמיד עם תקרת use Xk tokens, ובדוק /model לפני הרצה גדולה.
